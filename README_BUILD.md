# Drh Mandiri — Paket Build APK

Proyek ini disiapkan untuk dibuild otomatis oleh GitHub Actions.

## Cara build
1. Upload seluruh isi folder ini ke repository GitHub `Drh-Mandiri`.
2. Buka tab **Actions**.
3. Pilih workflow **Build Drh Mandiri APK**.
4. Tekan **Run workflow**.
5. Setelah selesai, buka hasil workflow.
6. Download artifact **Drh-Mandiri-APK**.
7. Di dalamnya terdapat `Drh-Mandiri.apk`.

Catatan: workflow memakai Gradle 8.9 dan JDK 17, sehingga repository tidak memerlukan Android Studio di komputer pengguna.
