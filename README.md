# Drh Mandiri

Aplikasi Android untuk pencatatan dan pembuatan laporan kegiatan Dokter Hewan Mandiri.

## Fitur versi 1.0
- Tambah, edit, hapus kegiatan
- Penyimpanan lokal/offline di perangkat
- Tanggal kegiatan
- Jenis pelayanan/penyakit
- Lokasi desa/kecamatan
- Jenis hewan
- Jumlah hewan
- Keterangan
- Filter laporan per bulan dan tahun
- Preview laporan
- Export PDF
- Export JPG
- Export DOC yang dapat dibuka di Microsoft Word
- Bagikan laporan ke WhatsApp/email/aplikasi lain
- Pengaturan nama dokter dan kota/kabupaten tanda tangan

## Cara build
1. Buka folder ini di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Pilih Build > Build APK(s).
4. APK debug akan dibuat di `app/build/outputs/apk/debug/`.

Catatan: file DOC dibuat sebagai dokumen HTML kompatibel Microsoft Word dengan ekstensi `.doc`.
